# Wayfarer

A thoughtfully paced Kyoto trip planner built with React, TypeScript, Vite, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

The trip dashboard includes an editable trip title, day-by-day itinerary, budget overview, light/dark theme switch, and a local travel copilot.
